# 2026-07-14

## 首页访问速度优化（全部完成）

对用户「分析并提升首页访问速度」的需求，实施了以下改动：

1. **`src/db.js`**：`init()` 用模块级 `schemaInitPromise` 记忆化，每个 isolate 仅执行一次 18 条建表/ALTER/索引语句（之前每个请求都跑）。
2. **`src/index.js`**：DB 初始化中间件从全局 `app.use('*')` 收紧为 `app.use('/api/*')`，SPA 静态路由不再访问 DB。
3. **`src/db.js` `findAllPosts`**：用 `COUNT(*) OVER()` 窗口函数合并分页与总数查询，省一次 D1 COUNT 查询。
4. **`frontend/src/composables/useAuth.js`**：匿名用户不再页面加载时请求 CSRF Token，改为首次写操作惰性获取。
5. **`frontend/src/views/RegisterView.vue`**：发送验证码 / 注册提交前加 `await auth.refreshCsrf()`，避免 403。
6. **`frontend/src/styles/theme.css` + `frontend/index.html`**：移除阻塞渲染的字体 `@import`，改为 `preconnect` + `stylesheet` link。
7. **`frontend/vite.config.js`**：`manualChunks` 拆出 vue vendor chunk，跨版本命中缓存。
8. **`wrangler.toml`**：`[assets]` 加 `run_worker_first = ["/api/*"]`。

验证：`npm run build` 成功，vendor chunk 已独立（`vue-*.js` ~97KB），`dist/index.html` 标题修正为「万象资讯」。
